# FPGA_based_game_design_using_LFSR

● A digital system is designed that implements a realistic T20 cricket game onto an  Spartan7 FPGA [Boolean Board] using Verilog HDL. 
● The algorithmic design consists of a linear feedback shift register (LFSR), comparator, adders, and counters. 
● The pseudorandom number generated by LFSR is assigned a value which is translated into runs, balls, extras, and wickets. 
● The system design is capable of producing realistic results, displaying a scoreboard that reflects team score and ball count, and 
displays winners on the board followed by the end-of-game celebration.
